# Сварэксперт

Перенос публичного сайта https://svar-experts.ru/ на GitHub и Vercel. Сохранены оригинальные страницы и оформление Tilda, 332 товара, 714 фотографий товаров, описания, характеристики, варианты и категории.

## Запуск

Node.js 22, без сторонних npm-зависимостей:

```sh
npm run build
npm run dev
```

Сайт: http://127.0.0.1:4173

## Хранение ресурсов

Все изображения, стили, скрипты и шрифты сохранены без потери качества. Из-за объёма около 500 МБ они хранятся в `asset-bundle/part-*`: это последовательные части единого tar.gz архива. `build.js` потоково распаковывает их в `public/assets` перед проверкой. Контрольные суммы частей — `asset-bundle/manifest.json`, карта исходных URL — `source/asset-map.json`.

Страницы и снимок каталога хранятся в `source-bundle.tar.gz` и автоматически восстанавливаются при сборке. Основной код API и сборки находится в обычных файлах репозитория.

## Структура

- `public/`: 343 HTML-страницы, локальный поиск и снимок каталога.
- `api/catalog.js`: локальный API с категориями, брендами и пагинацией, без зависимости от исходного каталога Tilda.
- `source/`: исходные ответы каталога и данные для повторной сверки.
- `migration-report.json`: количественный отчёт.
- `AUDIT.md`: анализ структуры и ограничений исходного сайта.
- `verify.js`: проверка количества товаров, страниц, всех фотографий и пагинации.

## Vercel

Framework: Other; Node.js 22; Build command: `npm run build`; Output directory: `public`.

Служебные формы Tilda сохранены вместе с исходными настройками. Доступ к приватным обработчикам заявок, CRM, заказам и платежам не входит в публичный HTML; реальную доставку заявок необходимо отдельно проверить в аккаунте владельца. Тестовые заявки при переносе не отправлялись.
